# GreenFuture – Umweltschutz

Eine moderne, responsive Website als Schulprojekt für die 10. Klasse.

## Dateien
- `index.html` – kompletter Seiteninhalt
- `style.css` – Design und responsive Layout
- `script.js` – interaktives Quiz und mobiles Menü

## Lokal testen
`index.html` im Browser öffnen.

## Kostenlos veröffentlichen
Zum Beispiel mit GitHub Pages:
1. Neues öffentliches GitHub-Repository erstellen.
2. Die drei Dateien hochladen.
3. In den Repository-Einstellungen unter Pages die Veröffentlichung aus dem `main`-Branch aktivieren.
4. GitHub stellt anschließend eine `github.io`-Adresse bereit.

## Hinweis zum Schulprojekt
Die Quellen auf der Website sind bewusst als Ausgangspunkte für die eigene Recherche angegeben. Bei konkreten Zahlen oder Aussagen sollte in der fertigen Schulabgabe die jeweils genaue Quelle und – wenn vorhanden – das Veröffentlichungsjahr ergänzt werden.
